Projenin Amacı
Bu projenin temel amacı; kurumsal Java standartlarına uygun, güvenli, sürdürülebilir ve yüksek performanslı bir e-ticaret web portalı geliştirmektir. Proje kapsamında Java Servlet, JavaServer Pages (JSP) ve JSP Standard Tag Library (JSTL) teknolojileri kullanılarak Model-View-Controller (MVC) mimarisine tam uyumlu bir web uygulaması tasarlanmıştır.
Uygulama, iki farklı kullanıcı rolüne (Müşteri ve Yönetici) hizmet vermektedir: - Müşteri Tarafı: Ürün kataloglama, kategori filtreleme, detaylı ürün analizi, oturum bazlı (session-based) alışveriş sepeti yönetimi ve ilişkisel veritabanına entegre sipariş oluşturma süreçlerini içerir. - Yönetici Tarafı (Admin Dashboard): Ürünlerin, kategorilerin, sipariş durumlarının ve kayıtlı kullanıcıların yönetilebildiği, istatistiksel raporların grafiksel olarak sunulduğu bir yönetim panelinden oluşur.
